About Me

Hi! My name is Abdalatif Zidan and I'm learning how to build software. I've been taking courses where I built a bunch of small projects to practice everything I learned, starting with basic HTML pages and CSS effects, then the Bootstrap framework, then JavaScript, and most recently C# and the .NET Framework.

Moving into C# is where things really opened up for me. Up to that point everything I built lived in the browser, and now I'm working with classes and interfaces, and using Entity Framework to put data into a real database instead of losing it the moment the page reloads.

This portfolio brings all of that work together in one place. Each project below has a link to the code on GitHub, and the web ones have a live demo you can click. The page itself uses JavaScript too — try the filter buttons, the dark mode switch in the menu, and the contact form. Thanks for stopping by!
